## 🚀 실행 방법

### 사전 요구사항

- Node.js (v16 이상)
- pnpm (권장) 또는 npm

### 설치 및 실행

2. **의존성 설치**

```bash
# pnpm 사용 (권장)
pnpm install

# 또는 npm 사용
npm install
```

3. **개발 서버 실행**

```bash
# pnpm 사용
pnpm dev

# 또는 npm 사용
npm run dev
```

4. **브라우저에서 확인**

http://localhost:5173

### 빌드 및 배포

```bash
# 프로덕션 빌드
pnpm build

# 빌드 결과 미리보기
pnpm preview
```

### 코드 품질 검사

```bash
# ESLint 실행
pnpm lint
```

## 📱 반응형 지원

- **PC 버전**: 1024px 이상
- **태블릿 버전**: 769px ~ 1023px
- **모바일 버전**: 768px 이하

각 디바이스에 최적화된 네비게이션과 레이아웃을 제공합니다.

## 🎯 핵심 페이지

### 1. 홈페이지 (`/`)

- 서비스 소개 및 주요 기능 안내
- 반응형 히어로 섹션과 기능 카드

### 2. 게시글 목록 (`/post`)

- 게시글 리스트 조회
- 카드 형태의 게시글 프리뷰

### 3. 게시글 상세 (`/post/:id`)

- 게시글 내용 상세 조회
- 댓글 및 대댓글 시스템
- 3D 모델 생성 진행 상태 표시

### 4. 게시글 작성 (`/post/create`)

- MP4 파일 드래그 앤 드롭 업로드
- 제목, 분류, 공개범위, 설명 입력
- 파일 크기 및 형식 검증 (최대 500MB)
